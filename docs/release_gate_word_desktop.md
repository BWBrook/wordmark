# Word Desktop Release Gate

Use this checklist when promoting agent-edited local copies into shared OneDrive/SharePoint document workflows.

## Inputs
- Baseline source document (unchanged shared reference copy).
- Edited local document generated by CLI/agent (for example `_edited_<dow><dd><mon><yyyy>.docx`).

## Checklist
1. Open both documents in Microsoft Word desktop (not Word for the web).
2. Run `Review > Compare` or `Review > Compare > Combine`:
   - Original: baseline
   - Revised: edited local copy
3. Review tracked changes and comments in the generated comparison document.
4. Accept/reject revisions in GUI until document reflects approved state.
5. Spot-check formatting/layout in high-risk regions:
   - lists/tables
   - images/captions
   - field-code-heavy sections
   - hyperlink-rich paragraphs
6. Save merged output with a versioned filename.
7. Upload/replace in shared storage only after approval.

## CLI helper
Generate a handoff summary without mutating inputs:

```bash
uv run wordmark review prepare-merge before.docx after.docx --json
```

Optional checklist report artifact:

```bash
uv run wordmark review prepare-merge before.docx after.docx --out artifacts/merge-checklist.json --json
```
